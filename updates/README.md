# Signed beta update feed

This directory is reserved for `beta.json`, generated by the Watchara CAD
release-signing tools. No placeholder feed is provided.

Publish a new signed feed only after the version-specific release asset,
first-install bundle and matching source/license materials are available and
the hosted asset passes the publisher's verification step. Then verify the
public feed against the locally signed envelope.

Never commit private keys, credentials, test-only localhost releases or unsigned
replacement metadata. Preserve previously published versioned assets.
